# valor-core

Shared canon for Valor Church staff. The "this is who we are" docs that every staff member's AI agent reads at session start.

## What this repo is

### Canon (the "this is who we are" files)

- **mission.md**: One-sentence purpose, four pillars, motto, tagline.
- **brand.md**: Fonts, palette, venue, address, service time, social, URL.
- **voice.md**: Voice and tone rules, hard rules, words to avoid.
- **convictions.md**: Theological, doctrinal, ministry philosophy, ecclesiological commitments.
- **stories.md**: Curated, share-safe stories from Valor's history and present.
- **references.md**: Evergreen scripture, frameworks, books, voices, tools.

### Agent and onboarding

- **CLAUDE.md**: Instructions for staff AI agents reading this canon.
- **STAFF-ONBOARDING.md**: New staff start here. Six-phase setup walkthrough.
- **templates/CLAUDE-template.md**: Starter for each staff member's personal CLAUDE.md.
- **templates/staff-workspace-starter.md**: Starter templates for department.md, workflows.md, references.md, tasks.md.

### Meta

- **README.md**: This file.

## What this repo is not

- Not Justin's personal workspace. That lives in `valor-church`, which stays private.
- Not a place for active task lists, financial figures, partner church specifics, or congregant PII.
- Not a substitute for each staff member's own workspace. Layer your own personal references, working files, and private notes on top of this canon.

## How staff use this

Each Valor staff member runs their own AI workspace. Clone this repo into your workspace and tell your `CLAUDE.md` to read these files at session start. Your agent then writes with the same voice, applies the same brand standards, and operates from the same doctrine as the rest of the team.

## Conventions

- Markdown only.
- **No em dashes anywhere in this repo.** Staff agents pull from these files to draft public copy, so the source models the rule. Use periods, colons, commas, or short sentences instead.
- All copy follows the voice and brand standards in `voice.md` and `brand.md`.

## Updates

Justin keeps the canonical version. When something changes, he updates this repo. Pull regularly. If you spot a gap or a typo, flag it to Justin so the master copy is corrected once and propagates to everyone.
